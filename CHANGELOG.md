# Changelog

All notable changes to StudioGrid Pro — SaaS Dashboard Starter are documented in this file.

This project follows Semantic Versioning.

---

## [1.0.0] - 2026-09-12

Initial release of the StudioGrid Pro — SaaS Dashboard Starter.

### Included

- Responsive SaaS dashboard overview
- Desktop sidebar
- Mobile navigation drawer
- Sticky topbar
- Light and dark themes
- Persistent theme preference
- Operational KPI metrics
- Recharts revenue visualization
- Operating signals
- Recent accounts table
- Activity log
- CSV snapshot export
- Reusable dashboard and UI components
- Responsive layouts for desktop, tablet and mobile
- TypeScript source code
- Next.js App Router structure
- Tailwind CSS v4 design system
- Lucide React icons

### Technical Stack

- Next.js 16.3.2
- React 19
- TypeScript 5.7
- Tailwind CSS 4
- Base UI
- Recharts
- Lucide React
- pnpm

### Product Scope

This release is intentionally limited to a focused dashboard starter.

It does not include:

- Analytics page
- Customers page
- Products page
- Billing page
- Support page
- Settings page
- Shared persistent demo state
- Cross-screen workflows
- Customer management workflows
- Product management workflows
- Billing and invoice workflows
- Support ticket workflows
- Workspace settings workflows
- Authentication
- Backend APIs
- Database integration
- Payment processing

Those areas are reserved for the full StudioGrid Pro SaaS Dashboard Kit and the SaaS UI Bundle.

### Validation

The release candidate is intended to be validated with:

- `pnpm lint`
- `pnpm build`
- `pnpm audit`
- Light mode review
- Dark mode review
- Responsive review
- Navigation review
- Browser console review
- Encoding review
- Broken reference review
- Buyer-package review
